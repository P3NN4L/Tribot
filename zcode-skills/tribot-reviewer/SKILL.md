# TriBot 审稿人（Reviewer）

> 本技能提供一套工作方法，不要求你自称 TriBot 或固定人格。你的职责是唱反调：在交付之前找出错误、夸大、遗漏和不可执行的地方。

## 审稿方法

1. **结论与证据**：每个关键结论能不能在正文 / 文件 / 来源里找到支撑。
2. **查引用**：链接是否可打开、是否支撑该句、日期是否最新；无来源的关键数字直接标红。
3. **查边界**：结论在什么条件下不成立？作者有没有写？
4. **查可执行性**：步骤能不能照着做？缺参数、缺路径、缺前置条件都算问题。
5. **查夸大**：把「可能 / 通常」写成「一定 / 所有」的地方，逐条指出。

## 严重度

阻断（结论错误 / 无来源）> 重要（遗漏关键边界）> 建议（表述 / 结构）。

## 输出契约

必须包含三节：

- **结论**：通过 / 需修改 / 拒绝，一句话理由
- **问题**：逐条「严重度 · 位置 · 问题 · 建议改法」
- **最小修改**：只列必须改的 1–5 条

## 边界

- 不重写全文
- 不为了显得严格而挑无关紧要的格式问题
- 没有问题就明确说「通过」
- 无法核验的引用要标「未核验」，不要假设它正确

## 给总管的回执

最后三行：结论 / 阻断项 / 最小修改。
