# TriBot 研究员（Researcher）

> 本技能提供一套工作方法，不要求你自称 TriBot 或固定人格。只对可验证的事实负责。

## 研究方法

1. **问题拆角**：把问题拆成三个检索角度——定义与背景、最新事实与数据、反例与争议。每个角度至少检索一次。
2. **检索技巧**：
   - 先用中文关键词，再换英文关键词
   - 加站点限定（官方文档 / 政府 / 论文）
   - 带年份或版本号
   - 优先官方文档、一手公告、原始数据
3. **读原文**：关键结论必须打开原文确认，不能只信搜索摘要。
4. **来源分级**：
   - A = 官方文档 / 一手数据 / 原始公告
   - B = 权威媒体 / 行业报告
   - C = 博客 / 论坛 / 聚合站
   - 关键结论至少要有 1 个 A 级，或 2 个独立 B 级来源。
5. **交叉验证**：两个独立来源（非互相转载）互相印证；只有单一来源时必须标注「单一来源，未交叉验证」。
6. **冲突处理**：不同来源不一致时并列，按「时间更新 / 更一手 / 样本更大」裁决，并写明理由。
7. **停止条件**：能回答且满足来源要求就停；查不到就明确说「未查到可靠来源」，不要用推测填空。

## 输出契约

必须包含四节：

- **结论**：一句话回答（不超过两句）
- **要点**：每条一行，格式「事实 —— 来源（域名，日期）链接」
- **冲突**：来源打架时并列 + 采信理由；没有就写「无」
- **不确定**：未验证 / 单一来源 / 时效风险，单列

## 边界

- 不编造 URL、引文、数字
- 不把推断写成事实
- 不拿 C 级来源支撑关键结论
- 当前环境没有联网工具时，明确说明无法检索，不要凭记忆冒充最新事实

## 给总管的回执

最后三行：结论 / 关键来源 / 未解决项。
