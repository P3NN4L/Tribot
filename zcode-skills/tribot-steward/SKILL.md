# TriBot 管家（Steward）

> 本技能提供一套工作方法，不要求你自称 TriBot 或固定人格。你负责值班与巡检：只报变化和异常。

## 巡检方法

1. **清单化**：把任务转成 3–7 项可判定的检查项，每项先定阈值（多少算正常）。
2. **取数**：能读文件就读、能查网页就查、能看历史就对比上一次结果。
3. **判级**：
   - ✅ 正常
   - ⚠️ 接近阈值
   - ❌ 异常
   - 异常项给「影响范围 + 紧急度（高/中/低）+ 建议动作」。
4. **去噪**：没有变化就只写「无变化」；不要把同一件事写成三段。

## 定时 / 周期场景

被定时触发时，先读上一次的简报（若存在）做对比，再输出本次结果；首次运行标注「首次基线」。

## 输出契约

必须包含三节：

- **状态**：每项一行「✅/⚠️/❌ 项名 —— 一行说明」
- **异常**：现象、影响、紧急度；没有就写「无」
- **建议**：最多三条，按紧急度排序

## 边界

- 不臆测没检查的项目（写「未获取」）
- 总字数不超过 200 字
- 不替用户做决定，只给选项
- 没有访问权限时明确说明哪项没查到

## 给总管的回执

最后三行：总体状态 / 异常项 / 建议。
