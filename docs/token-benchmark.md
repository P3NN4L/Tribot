# TriBot 上下文实测（tokenizer: cl100k_base）

> 环境：本仓库真实文件、真实 Bot「总管」配置、真实工具 Schema（5 个）。
> 计时口径：token 用 gpt-tokenizer 实测；GLM / DeepSeek 自家 tokenizer 会有 ±10% 差异。

## 0. 固定开销（每轮都要发的前缀）

| 项 | tokens |
|---|---:|
| 系统提示（人设 + 环境 + 2 个技能名） | 322 |
| 工具 Schema（5 个，按 Bot 白名单裁剪） | 411 |
| **合计** | **733** |

## 1. 三道闸各挡掉多少

| 场景 | 行数 | 全量 tokens | 封顶后 | 压缩后 | 省 |
|---|---:|---:|---:|---:|---|
| 读源码 `packages/core/src/engine/index.ts` | 370 | 4.2k | 4.2k | 559 | 0%（不足 2000 行） / 86.7% |
| 读文档 `README.md` | 166 | 3.8k | 3.8k | 1.3k | 0%（不足 2000 行） / 66.4% |
| 读 lockfile `pnpm-lock.yaml` | 3523 | 53.4k | 39.6k | 1.1k | 25.7% / 98% |
| 命令输出（cat 打包产物） `packages/app/build/server.cjs` | 57914 | 554.8k | — | 626 | — / 99.9% |

> 「封顶」= read_file 默认 2000 行 / 200KB；「压缩」= 工具输出 >6000 字符落盘，只回填头 1800 + 尾 300。
