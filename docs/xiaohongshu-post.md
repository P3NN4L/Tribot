# 原来DSH还能这样用？我给AI装了一个"人格切换器"

家人们谁懂啊！装了这个插件之后，我的DSH直接从"一个AI"变成了"一个团队"🤯

## 它是什么

一个 DSH 插件，一次装完，AI 自动拥有 5 种人格：

🧭 总管 → 只管拆任务、派活、验收
🔍 研究员 → 只负责查资料、验真伪
🛠 工程师 → 只管写代码、跑命令、贴报错
⏰ 管家 → 巡检查表，200字内说清楚
🧪 审稿人 → 交付前唱反调，专挑毛病

你说"用工程师修个bug"，它就直接入戏，不废话不旁白，第一行亮出角色然后开干。

## 为什么我推荐

**1️⃣ 不用写提示词了**

以前：复制粘贴一百行"你是一个资深工程师，你需要..."

现在：`/tribot 工程师`，五个字搞定。

**2️⃣ 审稿有四档**

简单审 → 中等审 → 深审 → 全审

发版前说一句"全审"，它会把每个链接、每个数字、每个引文逐条溯源。核不了的标"未核验"而不是瞎编。

**3️⃣ 真的省 token**

实测数据（不是营销号编的）：

📊 读 3705 行 lockfile：56k → 1.1k（省 98%）
📊 cat 一个 6 万行文件：615k → 626 tok（省 99.9%）
📊 长对话压缩：40 条历史省 59%

## 怎么装

一行命令：

```bash
dsh plugin --profile desktop add dsh-tribot-team
```

或者去 DSH Market 搜 TriBot 直接装。

装完重启，输入框旁边会多一个小胶囊——点一下选角色，不用记命令。

## 最戳我的细节

输入框旁边有个小开关，关了就退出角色，开了自动进入上次用的角色。

AI 不再是"万能但平庸"，而是**该干活的时候是工程师，该审查的时候是杠精**。

这就是我想要的工作方式。
