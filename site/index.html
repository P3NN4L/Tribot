API Key 怎么保护

目标：翻磁盘、拷安装目录，都拿不到明文 Key。

AT REST

AES-256-GCM 密文

凭证以 enc:v1: 落盘，不再是明文 JSON；拷走文件没有主密钥也解不开。

MASTER KEY

系统级保护

桌面版主密钥由 Windows DPAPI / macOS Keychain（Electron safeStorage）加密；纯命令行模式用本机兜底密钥。

SURFACE

界面只见尾号

渲染层只拿 hasKey 和 …sDpM；发布包里没有 data/、.env 或 Key 片段。

边界：同用户的恶意程序仍可读进程内存；本地客户端无法承诺防住本机管理员。能做的是静态文件、安装包、日志、界面都不泄露明文。

下载

Windows 是编译好的原生壳（C# + WebView2）；macOS / Linux 是 Python + 系统 WebView 的源码包。都不再打包 Electron。
