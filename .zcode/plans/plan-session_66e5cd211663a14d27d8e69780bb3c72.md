# TriBot — 跑在你电脑上的「Bot 团队工作台」（类 Grok Bot）

## 产品重定义

不做「多模型聊天 App」，做 Grok Bot 的本地版本质：**一队有名字、有职责、有记忆的 Bot，接到任务后用工具真干活**。你的电脑 = Bot 的电脑（替代云电脑），Electron 常驻托盘。

## 架构（pnpm monorepo，Node 24 + TypeScript）

```
packages/
├── core/     纯 TS 库：Bot 实体、工具执行器、模型路由、配额、记忆、Skill、Routine
├── server/   Fastify 包 core，HTTP + SSE 监听 127.0.0.1（App/CLI 共用）
├── app/      Electron + React/Vite 深色工作台 UI（托盘常驻、系统通知）
├── cli/      命令行客户端（tb chat / ask / bots / quota / run）
└── shared/   前后端共享类型
```

SQLite（better-sqlite3, WAL）：bots / sessions / messages / tasks / approvals / usage_events / skills / routines / settings。

## 七大核心模块

**1. Bot 实体 + 工作区群聊**
Bot = {名字, 头像, 职责 system prompt, 独立记忆, 工具白名单, 模型偏好}。界面是群聊工作区，@Bot 派活；内置四个：总管（调度拆解）、研究员（联网搜索）、工程师（终端/文件）、管家（定时巡检）。多 Bot 协作 v1 用「总管转发给专家 Bot」的简单编排。

**2. 任务五要素卡**
派活默认走结构化卡：目标/数据源/限制/交付物/审批点（对齐 Grok Bot）；也支持普通聊天。

**3. 本地工作电脑（工具执行器）**
每 Bot 独立目录 `data/workspaces/<bot>/`。工具：read_file / write_file / list_dir / run_command（命令白名单）/ web_search / http_fetch / browser（Playwright，M2）。**审批两档**（Ask first / Auto-allow），高危（删文件、网络外发、白名单外命令）强制弹审批卡，系统通知里批准/拒绝；全部执行留痕可审计。

**4. 动态模型路由（比 Grok Bot 更强）**
- 自动（默认）：任务分类 → 模型档位（简单→GLM-Flash/5-Turbo，复杂推理→GLM-5.3/DeepSeek-reasoner/M2）
- 配额感知：GLM/MiniMax 订阅（5h 窗口+周限）优先用满 → 溢出走 DeepSeek 按量；DeepSeek 峰谷时钟（工作日 9-12/14-18 高峰，夜间+周末半价）影响路由权重
- 容错降级：429/超时/额度错误自动切链，UI 显示降级原因
- 独有增强：手动锁定模型、同题对比（多模型并行、分栏答案可追问）

**5. Skill 库**
任意一次成功任务「一键存为 Skill」（prompt+工具+步骤模板，支持变量）；Bot 间共享，从模板新建任务。

**6. Routine（定时/事件任务）**
cron 定时 + 简单事件触发；后台静默执行，结果推送系统通知并落入 Bot 会话；保留执行历史。

**7. 配额仪表盘**
侧栏常驻三家胶囊：GLM `monitor/usage/quota/limit` 接口、MiniMax `coding_plan/remains`（若需 cookie 则降级）、DeepSeek `/user/balance` + 峰/谷状态；**本地 usage 自计量**（按响应 usage 记账 5h 窗口/周用量）做最可靠兜底；成本报表页。

## 分期
- **M1（本次）**：core + server + Electron 工作台（Bot/群聊/任务卡/文件+终端工具/审批门/四种路由策略/配额仪表盘/记忆）+ CLI 基础命令
- **M2（本次尽量）**：Routine + 系统通知、Skill 库、web_search（Tavily）、Playwright 浏览器工具、成本报表
- **M3（后续）**：多 Bot 深度编排、Telegram 接入（官方免费 API；微信无官方 API 不承诺）
